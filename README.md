## Project Description

This project is a simple command-line line editor written in C.
It allows users to create, modify, and display a small text document.

## Data Structure

The project uses an array of strings to store the document lines.

## Implemented Features

1. Insert Line
2. Delete Line
3. Display Document
4. Invalid line number handling

## How to Compile

Open the terminal in the project folder and run:

gcc main.c -o line_editor

## How to Run

Run the program using:

.\line_editor
