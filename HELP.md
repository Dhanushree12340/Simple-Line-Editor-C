# Simple Line Editor - Help

## Description

This is a simple command-line line editor written in C.
It allows users to insert, delete, and display lines of a document.

## Supported Commands

1. Insert Line
   - Enter the line number.
   - Enter the text to insert.

2. Delete Line
   - Enter the line number to delete.

3. Display Document
   - Displays all lines with their line numbers.

4. Exit
   - Exits the line editor.

## Example

1. Insert Line
2. Delete Line
3. Display Document
4. Exit

Enter your choice: 1
Enter line number to insert: 1
Enter the text: Hello World

Line inserted successfully!
